# PostGIS Patterns

Practical examples and tested patterns for working with PostgreSQL and PostGIS.

## Start here

- [Pattern guide](pattern-guide.md) — curated spatial SQL patterns and usage notes.
- [Repository README](https://github.com/ZQM-Computing/postgis-cookbook) — setup instructions, examples, and development workflow.
- [Runnable examples](https://github.com/ZQM-Computing/postgis-cookbook/tree/main/examples) — examples exercised by the repository's validation workflow.
- [Tests](https://github.com/ZQM-Computing/postgis-cookbook/tree/main/tests) — assertions and regression checks.

The examples are educational starting points. Validate query plans, spatial indexes, coordinate reference systems, and data-specific assumptions before using a pattern in production.
